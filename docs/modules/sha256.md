# sha256 — SHA-256 摘要

```ayanami
import "sha256";
```

纯 Ayanami 实现（32 位运算用 `int` 承载并逐步掩码 `0xffffffff`），无机器相关依赖。

| 函数 | 说明 |
|---|---|
| `sha256_bytes(ref String s) -> String` | 原始摘要（32 字节） |
| `sha256_hex(ref String s) -> String` | 十六进制摘要（64 字符小写） |

示例：

```ayanami
println(sha256_hex("abc"));
// ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

约定：

- 输入按字节处理（不做 UTF-8 校验）；
- 输出为 FIPS 180-4 标准 SHA-256，已用空串、单块、跨块向量验证；
- 大消息按 64 字节分块处理，消息长度按位大端写入尾部。

## 实现

1. 填充：追加 `0x80`，补零至 `len % 64 == 56`，再写 8 字节大端位长；
2. 消息扩展：`w[0..16]` 直接取块内大端字，`w[16..64]` 用 σ0/σ1 递推；
3. 压缩：64 轮，每轮 `T1 = h + Σ1(e) + Ch(e,f,g) + K[t] + w[t]`、
   `T2 = Σ0(a) + Maj(a,b,c)`，所有加法后掩码 32 位；
4. 输出：8 个状态字按大端拼成 32 字节。
