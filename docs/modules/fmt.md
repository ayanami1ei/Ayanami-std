# fmt — 编译期格式化宏

```ayanami
import "fmt";
```

`#format(fmt, args...)` 在**编译期**展开为字符串拼接，各参数调用其 `ToString::to_string()`。

| 写法 | 结果 |
|---|---|
| `#format("x={} y={}", 1, 2)` | `"x=1 y=2"` |
| `#format("{}", "hi")` | `"hi"` |
| `#format("{}{}", 1, 2)` | `"12"` |
| `#format("a {{b}} c")` | `"a {b} c"` |
| `#format("len={}", "hello".len())` | `"len=5"` |
| `#format("n={}", 42u8)` | `"n=42"` |
| `#format("[{:5}]", 7)` | `"[7    ]"` |
| `#format("[{:>5}]", 7)` | `"[    7]"` |
| `#format("{:x}", 255)` | `"ff"` |
| `#format("{:X}", 255)` | `"FF"` |
| `#format("{:b}", 5)` | `"101"` |
| `#format("{:o}", 8)` | `"10"` |
| `#format("{:>8x}", 255)` | `"      ff"` |

- `{}` 按顺序消费一个参数；`{{` / `}}` 输出字面量花括号；
- **宽度/对齐**：`{:N}` / `{:<N}` 左对齐补空格，`{:>N}` 右对齐补空格（超出宽度不截断）；
- **进制**：`{:x}` / `{:X}` / `{:b}` / `{:o}` 展开为 `.to_hex()` / `.to_hex_upper()` /
  `.to_bin()` / `.to_oct()`（仅限整数类型，可与宽度组合如 `{:>8x}`）；
- 占位符个数与参数个数不一致 → 编译错误（`diag_error`）；
- 参数可为任意实现 `ToString` 的表达式（`int` / `float` / `bool` / `char` / `String` /
  整数宽度 `u8..u64`、`i8..i32`）。

## 实现

文本宏（`#[macro]`，输入输出均为源码字符串）：
1. `input` 为实参原文（#217 修复），按**顶层逗号**切分（忽略字符串/括号内逗号）；
2. 首个参数须为字符串字面量，扫描其中的 `{}` / `{{` / `}}` 与规格
   `{: [<|>]? [0-9]* [xXbo]? }`；
3. 展开为 `"片段" + (表达式).to_string() + ...`；带进制说明时改用对应的
   `to_hex` / `to_hex_upper` / `to_bin` / `to_oct`，再按需 `.pad_left` / `.pad_right`。

> 依赖编译器 #215（变参宏）、#217（`input` 传入实参）、#216（宏插件 double free）修复。
